# Emplacement du Curriculum Vitae (PDF)

Pour rendre votre CV directement téléchargeable depuis le portfolio :
1. Déposez votre fichier au format PDF à la racine de `public/` sous le nom :
   `public/cv-aoudou-sehou.pdf`
2. Le bouton de téléchargement du portfolio pointera alors directement sur `/cv-aoudou-sehou.pdf`.
