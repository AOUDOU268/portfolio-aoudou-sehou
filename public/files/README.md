# Emplacement officiel du CV (PDF)

Pour activer le téléchargement direct du CV dans le portfolio :
1. Déposez votre véritable fichier CV au format PDF à l'emplacement exact :
   `public/files/cv-aoudou-sehou.pdf`
2. Dès que ce fichier est présent, le portfolio le détecte automatiquement, active le bouton de téléchargement et permet son téléchargement sous le nom `CV_AOUDOU_SEHOU.pdf`.
3. Si le fichier n'est pas encore déposé, l'application désactive proprement le bouton et affiche un message explicite invitant le visiteur à demander le CV par email direct (`aoudousehou@gmail.com`).
