# Emplacement des Captures d'Écran de Projets

Déposez ici les captures d'écran réelles et validées pour vos projets :
- `agrima-preview.png` : Capture du catalogue ou du tableau de bord AGRIMA
- `justiciable-cm-preview.png` : Capture de l'application mobile Flutter Justiciable CM
- `peag-cam-preview.png` : Schéma d'architecture ou interface PEAG CAM
- `quanta-core-preview.png` : Benchmark ou graphes d'évaluation d'entropie

Une fois ajoutées, associez-les dans le champ `media.screenshots` de `src/data/projects.ts`.
